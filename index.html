Selected work

Projects

01

MessageU

An encrypted client-server messaging app. A Python server and a C++ client talk over a custom binary TCP protocol. Messages are end-to-end encrypted: RSA wraps the shared key and AES encrypts the text, so the server only stores ciphertext. Server tests and the client build run on GitHub Actions CI.

  • Python
  • C++
  • TCP sockets
  • Binary protocol
  • RSA + AES
  • SQLite
  • GitHub Actions
02

Two-Pass Assembler

An assembler for a custom assembly language, written from scratch in C. A pre-assembler expands macros, the first pass builds the symbol table and encodes instructions, and the second pass resolves labels and writes the machine code, entry and extern files.

  • C (ANSI)
  • Macro expansion
  • Symbol table
  • Two passes
  • Machine code
03

WatchShelf

A REST API for a personal movie shelf, built with FastAPI. Add and search movies, mark them as watched or want-to-watch, rate them, and group them into lists, all stored in SQLite. Ships with a Dockerfile.
